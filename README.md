## About me

I build software embedded with the people who use it. I usually start by scoping the problem with stakeholders, then I own it all the way to production.

I've spent 6+ years across cloud infrastructure, full-stack development, and 1:1 technical consulting. I'm as comfortable setting up AWS infrastructure and CI/CD pipelines as I am sitting with a client and turning a vague idea into something shipped.

I tend to take ownership when things are ambiguous or under-resourced. I've been the sole engineer on a multi-tenant SaaS platform, the only web developer keeping a product alive through a budget restructuring, and the consultant writing proposals and roadmaps directly with enterprise and startup clients. I also like building things that make the whole team faster: org-wide CI/CD, shared component libraries, testing standards, internal tooling, and lately developer tools built on LLMs.

A few things I'm proud of:

- Cut deploy times from 40 minutes to 10 with GitHub Actions and a build-once, promote-many setup
- Shrunk our Docker images from 3GB to 500MB with multi-stage builds
- Rolled out Datadog and CloudWatch across the org and cut our time to recover from incidents by 40%
- Migrated 150+ legacy PHP APIs to NestJS and cut query latency by 45%
- Built an internal tool on the Anthropic API that takes local changes to an open PR: it runs the tests, suggests fixes, resolves merge conflicts, and writes the PR description
