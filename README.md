## 👋 About me

I build software embedded with the people who use it. I usually start by scoping the problem with stakeholders, then I own it all the way to production.

Over 6+ years I've worked across **cloud infrastructure, full-stack development, and 1:1 technical consulting**. I'm as comfortable setting up AWS infrastructure and CI/CD pipelines as I am sitting with a client and turning a vague idea into something shipped.

I tend to take ownership when things are ambiguous or under-resourced. I've been the sole engineer on a multi-tenant SaaS platform, the only web developer keeping a product alive through a budget restructuring, and the consultant writing proposals and roadmaps directly with enterprise and startup clients. I also like building things that make the whole team faster: org-wide CI/CD, reusable component libraries, testing standards, internal tooling, and lately **LLM-powered developer tools**.

An internal tool I built on the **Anthropic API** that takes local changes all the way to an open pull request:

```text

              ─▶ draft PR description from the diff ─▶ open the PR via the GitHub API
```
